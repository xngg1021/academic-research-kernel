Msingi wa utafiti wa kitaaluma usiofungamana na mfumo mahususi na seti ya majadiliano ya maajenti wengi. Hutoa ujuzi 13 wa kitaaluma na zana za uthibitishaji zenye sehemu za kuingilia zinazobebeka za Agent Plugins v1 na MCP (Model Context Protocol), pamoja na muunganisho asilia wa Hermes Agent, Claude Code, Cursor na maajenti wadogo wa CLI. Inajumuisha uthibitishaji wa vyanzo, uchambuzi wa maandiko, uhariri wa kitaaluma, ukokotoaji wa namba, ukaguzi wa machapisho ya kiasi, ukaguzi wa uwezo wa kurudia matokeo, mapitio ya kimfumo na uchambuzi meta, utambulisho na asili ya vitu vya utafiti, uratibu thabiti wa ukaguzi mtambuka kati ya mifano tofauti, na mifumo miwili ya ufuatiliaji wa kila wiki. Hifadhi ina mifano inayoweza kutekelezwa; upeo wa uthibitishaji na vikwazo vya huduma za nje vimerekodiwa katika [ripoti ya ukaguzi](../../docs/audit-20260906.md).

## Viwango vya Kitaaluma na Msingi wa Maelezo Mafupi Mbalimbali

Mitindo ya unukuu, vigezo vya kutoa taarifa na mikataba ya metadata hutegemea jarida lengwa, taasisi, mfadhili, taaluma na mamlaka ya kisheria. Hifadhi inaweka **ISO 690:2021** (Marejeleo ya kibiblia), **ISO 5127:2017** (Msamiati wa taarifa na nyaraka) na **W3C PROV** (Muundo wa data ya asili) kama misingi ya kimataifa, pamoja na wasifu wa kikanda na viwango vya kinidhamu (APA 7th, IEEE, ACM, Vancouver, Chicago, PRISMA 2020, ICMJE). Mahitaji ya eneo lengwa yana kipaumbele juu ya maelezo mafupi ya msingi. Tazama [Muundo wa Viwango vya Kitaaluma](../../docs/standards/README.md) na [Mwongozo wa Istilahi Asilia](../../docs/terminology/README.md).

## Muunganisho na Matumizi Yanayohamishika

### 1. Universal Agent Plugins v1 & Model Context Protocol (MCP)
Hifadhi hii inatii vipimo visivyofungamana na muuzaji vya **Agent Plugins v1** (`../../plugin.json`) na inaonyesha zana za msingi za uthibitishaji wa kitaaluma na ukokotoaji wa takwimu kupitia **seva ya MCP** ya stdio (`../../mcp.json` / `python scripts/mcp_server.py`). Inaoana na Claude Code, Cursor, Gemini CLI na mfumo wowote wa kisasa wa maajenti.

```bash
# Add as stdio MCP server in your agent harness
python scripts/mcp_server.py
```

### 2. Usakinishaji Asilia katika Hermes
Kutoka kwa mazingira ya usakinishaji wa Hermes fanya yafuatayo:

```bash
hermes skills tap add xngg1021/academic-research-kernel
hermes skills search academic-source-verification
hermes skills install xngg1021/academic-research-kernel/skills/academic-source-verification
```

Sakinisha ujuzi mwingine kwa kubadilisha jina la saraka katika kitambulisho kamili. Tap ya kawaida husoma tawi chaguo-msingi. Ujuzi unaohusiana uliopimwa kwenye ahadi `245e48008fa814b3251f50755eb656bd9fb86cb1`: arxiv, grounded-citations, docx, pdf, manim-video.

## Ufikiaji wa Vyanzo vya Data

- Maswali ya msingi ya OpenAlex yanaweza kuendeshwa bila kujulikana kwa bajeti ndogo ya kila siku ($0.10/siku bila kujulikana na $1/siku na ufunguo wa bure wa API, kikomo cha maombi 100/sekunde). Hifadhi ufunguo wa hiari katika `OPENALEX_API_KEY`.
- Crossref hutoa ufikiaji wa metadata ya umma kwa udhibiti wa kasi. Masasisho na ishara za Retraction Watch zinahitaji ukaguzi wa DOI.
- Unpaywall inahitaji barua pepe halisi ya mawasiliano katika `UNPAYWALL_EMAIL`.
- arXiv, Europe PMC, PubMed na DOAJ ni vyanzo vya ziada vilivyo na sera zao. Scite, Dimensions, Scopus na Web of Science ni huduma za hiari za nje.

## Uthibitishaji na CI

Tumia mazingira maalum ya Python. Mahitaji ya QA yanajumuisha ukaguzi wote unaoweza kutekelezwa:

```bash
python -m pip install -r requirements-qa.txt
python -m pip install 'torch>=2.5,<3' --index-url https://download.pytorch.org/whl/cpu
python scripts/qa.py
python -m pytest -q tests
python scripts/verify_external_apis.py
git diff --check
```

QA inathibitisha metadata, marejeleo, mifumo ya njia za kibinafsi/siri, sintaksia ya Python na vizuizi vya msimbo vilivyowekwa alama. Hutoa 0 kwa mafanikio, 1 kwa hitilafu ya msimbo/schema/utambulisho na 2 kwa kutopatikana kwa mtandao/uthibitishaji/kiwango.

CI huendesha majaribio kamili kwenye Linux x86_64 (Python 3.10-3.14), Linux ARM64, Ubuntu 26.04 Preview, Windows x86_64, Windows ARM64, macOS ARM64 na macOS Intel, huku majaribio 666 ya vitengo yakifaulu na vizuizi 40 vya msimbo vinavyotekelezeka vikiwa vimethibitishwa.

tools/longtail/ inashikilia jenereta ya hali ngumu: michanganyiko 4096 ya wagombea yenye mbegu ya SHA256 na ripoti ya chanjo katika generated-scenarios.json.

scripts/scfabric/ ni muundo wa kompyuta ya kisayansi: uchunguzi wa vifaa, orodha ya nyuma na vichungi vya dtype, wasifu tano wa mzigo wa kazi na ComputeReceipt. Vipimo viko katika [docs/scientific-compute-fabric.md](../../docs/scientific-compute-fabric.md).
