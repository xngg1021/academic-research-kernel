Нейтральное ядро академических исследований и набор многоагентного рецензирования. Предоставляет 13 академических навыков и инструментов верификации с точками входа Agent Plugins v1 и MCP (Model Context Protocol), а также нативную интеграцию для Hermes Agent, Claude Code, Cursor и пользовательских субагентов CLI. Охватывает верификацию источников, анализ литературы, научное редактирование, численные расчеты, количественный аудит статей, аудит воспроизводимости, систематические обзоры и мета-анализ, идентификацию и происхождение исследовательских объектов, динамическую оркестрацию перекрестного рецензирования, а также две еженедельные службы мониторинга. Репозиторий включает исполняемые примеры; область проверки и ограничения внешних сервисов зафиксированы в [аудите](../../docs/project-lineage-audit-20260920.md).

## Академические стандарты и многопрофильная основа

Стили цитирования, критерии отчетности и метаданные зависят от целевого журнала, учреждения, фонда, дисциплины и юрисдикции. Репозиторий устанавливает **ISO 690:2021** (Библиографические ссылки), **ISO 5127:2017** (Терминология информации и документации) и **W3C PROV** (Модель данных о происхождении) в качестве международных стандартов, наряду с региональными профилями и дисциплинарными нормами (APA 7th, IEEE, ACM, Vancouver, Chicago, PRISMA 2020, ICMJE). Требования целевого издания имеют приоритет перед профилями по умолчанию. См. [Архитектуру стандартов](../../docs/standards/README.md) и [Руководство по терминологии](../../docs/terminology/README.md).

## Интеграция и переносимое использование

### 1. Universal Agent Plugins v1 & Model Context Protocol (MCP)
Репозиторий соответствует нейтральной спецификации **Agent Plugins v1** (`../../plugin.json`) и предоставляет основные инструменты верификации и расчетов через **сервер MCP** со stdio (`../../mcp.json` / `python scripts/mcp_server.py`). Совместим с Claude Code, Cursor, Gemini CLI и любыми современными средами агентов.

```bash
# Add as stdio MCP server in your agent harness
python scripts/mcp_server.py
```

### 2. Нативная установка в Hermes
Из среды установки Hermes выполните:

```bash
hermes skills tap add xngg1021/academic-research-kernel
hermes skills search academic-source-verification
hermes skills install xngg1021/academic-research-kernel/skills/academic-source-verification
```

Установите остальные навыки, заменив имя каталога в идентификаторе. Стандартный tap читает ветку по умолчанию. Связанные навыки проверены на коммите `245e48008fa814b3251f50755eb656bd9fb86cb1`: arxiv, grounded-citations, docx, pdf, manim-video.

## Доступ к источникам данных

- Базовые запросы к OpenAlex можно выполнять анонимно с ограниченным дневным лимитом ($0.10/день анонимно, $1/день с бесплатным ключом, лимит 100 запр./сек). Храните ключ в `OPENALEX_API_KEY`.
- Crossref предоставляет публичный доступ к метаданным с ограничением частоты. Сигналы обновлений и Retraction Watch требуют сверки DOI.
- Unpaywall требует рабочий контактный адрес в `UNPAYWALL_EMAIL`.
- arXiv, Europe PMC, PubMed и DOAJ являются дополнительными источниками со своими правилами. Scite, Dimensions, Scopus и Web of Science — дополнительные внешние сервисы.

## Верификация и тестирование

Используйте выделенное окружение Python. Зависимости QA обеспечивают выполнение всех проверок:

```bash
python -m pip install -r requirements-qa.txt
python -m pip install 'torch>=2.5,<3' --index-url https://download.pytorch.org/whl/cpu
python scripts/qa.py
python -m pytest -q tests
python scripts/verify_external_apis.py
git diff --check
```

QA проверяет метаданные, ссылки, шаблоны путей и секретов, синтаксис Python и исполняемые блоки. Возвращает 0 при успехе, 1 при ошибке кода/схемы, 2 при недоступности транспорта или квот.

CI выполняет полный набор тестов на Linux x86_64 (Python 3.10-3.14), Linux ARM64, Ubuntu 26.04 Preview, Windows x86_64, Windows ARM64, macOS ARM64 и macOS Intel, с 713 пройденными модульными тестами и 40 исполняемыми блоками кода.

tools/longtail/ содержит генератор детерминированных сценариев длинного хвоста: 4096 комбинаций кандидатов на базе SHA256, жадный выбор покрытия и отчет в generated-scenarios.json.

scripts/scfabric/ — инфраструктура научных вычислений: аппаратный зонд, каталог бэкендов с проверкой типов, 5 профилей нагрузки и ComputeReceipt. Измерения в [docs/scientific-compute-fabric.md](../../docs/scientific-compute-fabric.md).
