## अकादमिक मानक और बहु-प्रोफ़ाइल आधार रेखा

उद्धरण शैलियाँ, रिपोर्टिंग मानदंड और मेटाडेटा अनुबंध लक्षित पत्रिका, संस्थान, वित्तपोषक, अनुशासन और क्षेत्राधिकार पर निर्भर करते हैं। रिपॉजिटरी अंतरराष्ट्रीय आधार रेखा के रूप में **ISO 690:2021** (ग्रंथसूची संदर्भ), **ISO 5127:2017** (सूचना और प्रलेखन शब्दावली) और **W3C PROV** (उत्पत्ति डेटा मॉडल) को क्षेत्रीय प्रोफाइल और अनुशासनात्मक मानकों (APA 7th, IEEE, ACM, Vancouver, Chicago, PRISMA 2020, ICMJE) के साथ स्थापित करती है। [अकादमिक मानक वास्तुकला](../../docs/standards/README.md) और [प्राकृतिक शब्दावली गाइड](../../docs/terminology/README.md) देखें।

## एकीकरण और पोर्टेबल उपयोग

### 1. Universal Agent Plugins v1 & Model Context Protocol (MCP)
यह रिपॉजिटरी विक्रेता-तटस्थ **Agent Plugins v1** विनिर्देश (`../../plugin.json`) के अनुरूप है और stdio **MCP सर्वर** (`../../mcp.json` / `python scripts/mcp_server.py`) के माध्यम से मुख्य शैक्षणिक सत्यापन और सांख्यिकीय पुनर्गणना उपकरण प्रस्तुत करती है। Claude Code, Cursor, Gemini CLI और किसी भी आधुनिक एजेंट फ्रेमवर्क के साथ संगत।

```bash
# Add as stdio MCP server in your agent harness
python scripts/mcp_server.py
```

### 2. हर्मीस में मूल संस्थापन (Hermes Installation)
हर्मीस संस्थापन परिवेश से इसे निष्पादित करें:

```bash
hermes skills tap add xngg1021/academic-research-kernel
hermes skills search academic-source-verification
hermes skills install xngg1021/academic-research-kernel/skills/academic-source-verification
```

पूर्ण पहचानकर्ता में निर्देशिका नाम को प्रतिस्थापित करके अन्य कौशल संस्थापित करें। सामान्य टैप डिफ़ॉल्ट शाखा को पढ़ता है। कमिट `245e48008fa814b3251f50755eb656bd9fb86cb1` पर जांचे गए बंडल कौशल: arxiv, grounded-citations, docx, pdf, manim-video.

## डेटा स्रोत पहुंच

- OpenAlex बुनियादी प्रश्नों को छोटे दैनिक बजट ($0.10/दिन अनाम और मुफ्त API कुंजी के साथ $1/दिन, 100 अनुरोध/सेकंड सीमा) के साथ अज्ञात रूप से चलाया जा सकता है। वैकल्पिक कुंजी `OPENALEX_API_KEY` में संग्रहीत करें।
- Crossref दर सीमा के साथ सार्वजनिक मेटाडेटा पहुंच प्रदान करता है। अद्यतन और Retraction Watch संकेतों के लिए DOI जांच आवश्यक है।
- Unpaywall के लिए `UNPAYWALL_EMAIL` में एक वास्तविक संपर्क ईमेल की आवश्यकता होती है।
- arXiv, Europe PMC, PubMed और DOAJ अपनी नीतियों के साथ पूरक स्रोत हैं। Scite, Dimensions, Scopus और Web of Science वैकल्पिक बाहरी सेवाएं हैं।

## सत्यापन और सीआई (CI)

एक समर्पित पायथन परिवेश का उपयोग करें। क्यूए निर्भरताएं सभी निष्पादन योग्य जांचों को कवर करती हैं:

```bash
python -m pip install -r requirements-qa.txt
python -m pip install 'torch>=2.5,<3' --index-url https://download.pytorch.org/whl/cpu
python scripts/qa.py
python -m pytest -q tests
python scripts/verify_external_apis.py
git diff --check
```

QA मेटाडेटा, संदर्भों, व्यक्तिगत पथ/गुप्त पैटर्न, पायथन सिंटैक्स और चिह्नित कोड ब्लॉक को मान्य करता है। सफलता पर 0, कोड/स्कीमा विफलता पर 1 और परिवहन/कोटा अनुपलब्धता पर 2 लौटाता है।

CI Linux x86_64 (Python 3.10-3.14), Linux ARM64, Ubuntu 26.04 Preview, Windows x86_64, Windows ARM64, macOS ARM64 और macOS Intel पर पूर्ण परीक्षण सूट चलाता है, जिसमें 713 यूनिट परीक्षण उत्तीर्ण और 40 निष्पादन योग्य कोड ब्लॉक सत्यापित हैं।

tools/longtail/ नियतात्मक चरम लंबी-पूंछ परिदृश्य जनरेटर रखता है: वियोजित कारक अक्षों पर 4096 SHA256-बीज संयोजन और generated-scenarios.json में कवरेज रिपोर्ट।

scripts/scfabric/ वैज्ञानिक कंप्यूटिंग फैब्रिक है: हार्डवेयर जांच, डेटा प्रकार गेटेड बैकएंड कैटलॉग, पांच वर्कलोड प्रोफाइल और ComputeReceipt। माप [docs/scientific-compute-fabric.md](../../docs/scientific-compute-fabric.md) में दर्ज हैं।
