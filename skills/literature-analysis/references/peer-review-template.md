# 模拟审稿模板(Peer Review Template)

## 声明(必须写在输出开头)

这是模拟审稿,由模型按标准审稿框架生成,不替代真实同行评审,不构成任何投稿/录用/退稿的正式意见。真实审稿有保密义务与利益冲突审查,本模板不适用真实投稿场景。

## 评审框架

逐节评审,每节给"优点 / 问题 / 建议"三栏。每一处批评必须定位到论文具体段落(引原文或段落号),不允许泛泛而谈。

| 节 | 要回答的问题 |
| --- | --- |
| 1. 贡献与新颖性 | 这篇论文的核心贡献是什么?与已有工作的差异是实质性的还是包装性的?claim 的强度与实际证据匹配吗? |
| 2. 方法与实验设计 | 方法描述是否可复现(数据、超参、环境、种子)?基线选择是否公平?消融实验是否回答了"哪个组件起作用"?评价指标是否贴合问题? |
| 3. 结果有效性 | 统计检验是否恰当(显著性、效应量、置信区间)?有无多重比较校正?结果是否由少量样本/特定种子支撑?误差棒与方差报告了吗? |
| 4. 结论与证据的匹配 | 每个结论句能否在实验里找到直接证据?有无"结果 A 推出结论 B"的跳跃?摘要与结论是否夸大了实验部分? |
| 5. 局限声明 | 论文自己承认了哪些局限?漏了哪些明显局限(数据偏差、泛化边界、计算成本)? |
| 6. 伦理与可复现 | 数据采集是否合规?代码/数据是否开源?有无可复现性声明? |

## 终评

- 评分:5=接收,4=小修,3=大修,2=拒稿(可重投),1=强拒。
- 决定性理由三条,每条一句话,对应到具体章节。
- 给作者的可执行修改清单,按优先级排序。

## 输出格式

```
【模拟审稿声明】……

【论文】<标题>, <年份>, <作者数> 位作者

一、贡献与新颖性
优点:……
问题:……(见第 X 节第 Y 段:"<原文>")
建议:……

(二至六节同上)

七、终评
评分:3/5(大修)
决定性理由:
1. ……
2. ……
3. ……
修改清单(按优先级):
- [高] ……
- [中] ……
- [低] ……
```

## 审稿语气规则

使用中性、客观且具有建设性的语言。审稿意见对事不对人。避免使用“令人失望”或“水平低下”等情绪化词汇，宜表述为“当前实证数据尚不足以支撑该结论”或“该消融实验未能明确区分变量 A 与 B 的独立贡献”。每个评议部分至少列出一项具体优点，避免单一否定。
