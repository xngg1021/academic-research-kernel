# 效应量归一与互转速查表

所有公式在 `../scripts/meta_core.py` 有对应实现,测试用例见仓库 tests/test_systematic_review.py。
记号:n1/n2 两组样本量,p0 对照组事件率,df = n1 + n2 - 2。

## 1. 标准化均差族(连续结局)

| 量 | 公式 | 方差 | 备注 |
| --- | --- | --- | --- |
| Cohen's d | (m1 − m2) / s_pooled,s_pooled = √[((n1−1)s1² + (n2−1)s2²)/df] | (n1+n2)/(n1 n2) + d²/(2df) | 小样本系统性偏高 |
| 校正因子 J | 1 − 3/(4df − 1) | — | df ≥ 10 时 J > 0.98 |
| Hedges' g | J · d | J² · var(d) | 合并前统一归一到 g |

均差类前提:两组独立、结局连续、方差可合并。交叉试验、整群随机、重复测量不能直接套,先按设计效应折算有效样本量。

## 2. 二分类结局族

| 转换 | 公式 | 前提 |
| --- | --- | --- |
| log OR(四格表) | ln(a·d / b·c),var = 1/a + 1/b + 1/c + 1/d | 任一格子为 0 先加 0.5 连续性校正 |
| OR → RR | OR / (1 − p0 + p0·OR) | 需要外部给定 p0;p0 越大概率差越大 |
| RR → OR | RR(1 − p0) / (1 − p0·RR) | 同上 |
| d → log OR | (π/√3) · d ≈ 1.8138 d | logistic 分布桥接,近似式 |
| log OR → d | (√3/π) · lor ≈ 0.5513 lor | 同上 |
| var(lor) ← var(d) | (π²/3) · var(d) | 与上两步配套 |

事件罕见(p0 < 0.05)时 OR 与 RR 接近,但不能仅凭 p0 小就允许混用:按本表公式,相对偏差 |1 − RR/OR| = p0·(OR−1)/(1 − p0 + p0·OR),例:p0=0.01、OR=100 时 RR≈50.25,偏差近 50%。默认统一到 log OR 尺度再合并;仅当给定 p0 与 OR 后相对偏差 ≤ 5% 才允许 OR/RR 混用,并在报告注明近似误差。

## 3. 相关与均差互转

| 转换 | 公式 |
| --- | --- |
| d → r(等组) | d / √(d² + 4) |
| d → r(不等组) | d / √(d² + a),a = (n1+n2)²/(n1 n2) |
| r → d(等组) | 2r / √(1 − r²) |

r 来自双变量相关研究、d 来自组间对比研究时,互转只用于探索性合并;正式分析按研究设计分层。

## 4. 合并与异质性

| 量 | 公式 | 判读 |
| --- | --- | --- |
| 固定效应 θ_F | Σ w y / Σ w,w = 1/v | 假设共同真效应 |
| Cochran's Q | Σ w (y − θ_F)² | df = k−1;检验效能随 k 低 |
| I² | max(0, (Q − df)/Q) | 25%/50%/75% 为低/中/高经验界值 |
| τ²(DL) | max(0, (Q − df)/C),C = Σw − Σw²/Σw | 研究间方差;随机效应权重 w* = 1/(v + τ²) |
| 随机效应 θ_R | Σ w* y / Σ w* | τ² = 0 时与固定效应相同 |

I² 受研究规模影响大,报告时同时给 Q 与 τ²,不只看 I² 百分比。

## 5. 发表偏倚诊断

| 方法 | 判读 | 限制 |
| --- | --- | --- |
| 漏斗图 | 目测对称性,横轴效应、纵轴标准误(倒三角) | 主观;异质性大时形状误导 |
| Egger 检验 | SND = y/√v 对精度 1/√v 回归,截距 ≠ 0 提示不对称 | k < 10 不建议;异质性高时假阳性 |
| trim-and-fill | 迭代估计被削去的研究数 k0,镜像补全后重估 | 校正后估计偏保守;I² 高时 k0 不稳 |

三条路都依赖"小研究效应"假设:不对称也可能来自真实异质性或小研究方法学质量差,不能直接等同于发表偏倚。正式报告建议 funnel + Egger 同行,trim-and-fill 作敏感性分析,并以 R `metafor` 复核。

## 6. 报告清单(与 PRISMA 2020 条目对应)

- 每个结局写明效应量类型、方向约定、合并模型与 τ² 估计法。
- 森林图标出各研究权重与 95% CI。
- 异质性:Q、df、p、I²、τ² 五件套全报。
- 敏感性:leave-one-out 范围(剔除后估计的最大/最小值)与任何高偏倚风险研究的剔除结果。
- 发表偏倚:漏斗图、Egger 截距与 p、k ≥ 10 才给 trim-and-fill。
