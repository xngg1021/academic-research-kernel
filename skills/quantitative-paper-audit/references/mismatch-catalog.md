# 错配类型清单与判定规则

八类可识别错配。每类给出判定入口、容差依据、常见良性解释与报告模板。判定分两级:“不一致”(超出报告精度容差,可能是舍入或转录问题)与“不可能”(违反数学上界,必然有误)。报告时只用这两级措辞,不写“造假”“错误”等定性词。

## 1. p 值不一致

入口:`check_p_match(reported_p, recomputed_p)`;重算 p 来自 `p_from_t` / `p_from_f` / `p_from_chi2` / `z_from_beta_se`。

判定:reported 保留 k 位小数时容差 0.5·10^-k。报告为“p < .05”形式时只做方向核对:重算 p 小于阈值即一致。

良性解释:单侧/双侧混淆、统计量本身被舍入(先反推统计量的舍入区间再判)、论文用了校正方法(如 Greenhouse-Geisser)而未注明。

## 2. CI 不一致

入口:`check_ci_consistency`。点估计偏离 CI 中点超过 rel_tol(默认 2%)即报不一致;比值类指标必须置 log_scale=True。

良性解释:CI 由 bootstrap 或剖面似然生成(天然不对称),此时中点检查不适用,只能核对宽度量级;实现里 log/算术两尺度各跑一次,任一尺度通过则标“待人工确认”而非错配。

## 3. 百分比分母错配

入口:`check_percentage(count, percent, denominator=None)`。

判定:给了声明分母,直接重算 100·count/denominator 与报告百分比按精度容差比对;没给分母,反推隐含分母 100·count/percent,最近整数回算仍超差即报不一致。

良性解释:表格分母与正文分母不同(如“占有效应答的 33.3%”),先确认百分比口径再判。

## 4. 效应量错配

入口:`cohens_d(..., reported=论文报告的 d)`;difference 超出报告精度可解释范围即报不一致。d 只给 1 位小数时,|difference| ≤ 0.05 视为舍入兼容;给 2 位时阈值 0.005。

良性解释:作者报的是 Glass's Δ(用对照组 SD)或 Hedge's g 而标成 d;把三组数都算出来对一遍,对得上就在报告里注明口径差异。

## 5. 表格与正文不一致

入口:`values_agree(表内值, 正文值)`。同一统计量在摘要、正文、表格中出现多次时两两核对。

良性解释:版本不同步(正文改了表格没改);这在数值层面仍是错配,照报,措辞用“两处报告值不一致”。

## 6. 不可能的 SD/范围

入口:`check_sd_possible(sd, minimum, maximum, n)`。超过上界即“不可能”,这是硬结论。

常见根因:把 SE 当 SD 报告(相差 sqrt(n) 倍,可反推验证)、量表范围记错、SD 与方差混淆(平方关系)。报告里先给出这三种换算哪个能对上,再下结论。

## 7. 样本量不一致

入口:`check_sample_size_from_df(df, reported_n, kind)`。等式精确,无容差。

良性解释:论文报的是分析样本量而 df 对应某子分析;缺失值剔除后各检验的 N 不同属正常现象,核对时取与该统计量同段落的 N。

## 8. 多重比较表述含糊

无可编程判定,人工核对清单:

- 全文出现多少组 p 值,作者是否说明哪些经过了多重性校正、用了哪种方法(Bonferroni、BH 等)。
- 结局指标是否区分主要/次要;p 值星号注释的阈值是否唯一。
- 亚组分析的 p 值是否与交互作用检验混用(亚组各自显著 ≠ 交互显著)。

标注格式:列出发现位置(页码/表号)+ 含糊点描述 + 需要作者澄清的问题,不给数值结论。

## 报告模板

每条错配按五行输出:

```
位置:表 2 / 第 4 页结果第 2 段
类型:p 值不一致
报告值:t(58) = 2.10, p = 0.02
重算值:p = 0.0402(scipy.stats.t.sf,双侧,df=58)
判定:不一致(超出 2 位小数舍入容差 ±0.005)
```

输入缺项导致无法重算时输出“无法判定(缺自由度)”并列入 receipt 的 failures,不猜。
