# 学术知识工作痛点图集，第 0 版

状态：工作清单，2026-09-16 汇编。材料来源为公开社区讨论、已发表调查报告与实证研究；定量论断逐条标注核实状态。本文记录摩擦点，不记录其相对频率。

## 一、范围与方法

本图集按研究生命周期枚举学术知识工作中的摩擦，覆盖从发现到维护与学习的全过程。条目经多模型对公开来源的交叉综合整理而成。本图集是枚举性的：不对痛点按频率排序，也不声称所列摩擦在现有工具中均无解。各架构原语对痛点的相对覆盖度，交由研究计划（docs/research-plan-v0.zh.md）中的因子分解矩阵处理。

## 三、痛点清单

条目按生命周期分区，每条为一个摩擦点，行文从简。

### 发现

- 相关材料散落于 Scholar、PubMed、arXiv、会议、RSS、邮件与同事消息之间。
- 提醒流高度重叠，真正相关的只占少数。
- 检索只显示找到了什么，从不显示漏掉了什么。
- 三年前读过的论文被当作新发现。
- 换一个同义词，结果集面目全非。
- 跨学科术语差异切断召回。
- 奠基性、增量、复现与批判性工作混在同一相关度排序里。
- 被引数与对当前问题的有用性被混为一谈。
- 会议、预印本与期刊版本作为独立条目进入阅读队列。

### 阅读队列

- 收藏速度远超阅读能力增长。
- 保存理由没有记录，几个月后用途丢失。
- 重要、有趣与也许有用混在同一收藏夹。
- 只看摘要、精读全文、只看图表、完整复算，没有统一粒度。
- 优先级不随当前项目重排。
- 重新变得重要的旧论文不会重新浮现。

### 文献身份

- DOI、arXiv ID、PMID、OpenAlex ID 与出版方 URL 是同一对象的多个名字。
- 预印本与正式版没有可靠归并。
- 会议版与期刊扩展版难以配对。
- 更正、勘误与撤稿通知难以追溯到原文。
- 补充材料与正文断链。
- 书章、专著、学位论文与会议录被元数据匹配器误配。
- 作者重名、改名、拼写变体与中文姓名倒置把同一个人切碎。
- 出版方 PDF、作者稿与预印本是同一作品的多个二进制版本。
- 文献管理器里已合并的条目，在 Word 文档中残留旧的嵌入引用身份。

### 获取全文

- 开放获取副本存在多处，哪份最好不清楚。
- 出版方的 403 分不清付费墙、反爬与瞬时故障。
- 机构代理 URL 跨设备失效。
- 补充材料压缩包、代码与数据散落在互不相干的站点。
- 源页面腐烂；存档快照与当前版本之间没有谱系。

### PDF 与文档解析

- 双栏阅读顺序被错误重建。
- OCR 毁掉公式、上下标与希腊字母。
- 表格视觉完好，复制即乱。
- 部分数据只存在于图中，没有原始数值。
- 脚注与尾注被解析器丢弃。
- 一个论断的方法细节横跨正文、方法、附录与 GitHub 仓库。

### 笔记

- 做笔记本身成了第二份工作。
- 读完做了笔记，日后仍要重读原文。
- 摘录丢失页码、章节与语境。
- 转述久了自己也分不清哪些是作者原话。
- 同一条论断抄进多个项目笔记后开始分叉。
- 标签体系膨胀到所有者自己都不再用。
- 主题标签无法表达支持、反对、方法与例证关系。
- 笔记定格在写下那年的理解。
- 事实过时与解释变化无从区分。

### 引用与证据

- 记得某篇论文说过，找不到是哪篇。
- 找到了引用，找不到原始论断在哪一页。
- 引文的引文替代了阅读原始来源。
- 一条引用只支持半句话，却被挂在整个断言上。
- 二手引用丢掉了原文的限定条件。
- 更正与撤稿不会传导到旧稿。
- 一个数字经过层层综述抄写后来源丢失。
- 图里的数字与正文的数字对不上。

### 概念与术语

- 同一术语在不同领域含义不同。
- 定义随年代漂移。
- 新论文换个名字重新发明旧概念。
- 缩写撞车。
- 公式符号相同而定义不同。
- 一个领域的默认假设在另一个领域不成立。

### 研究空白

- 没搜到被当成没人做过。
- 只搜英文制造虚假的新颖性。
- 学位论文、会议录与预印本被跳过。
- 旧术语把历史工作挡在召回之外。
- 一篇不知名的论文可能早已填掉所谓的空白。
- 没有研究与研究结果不一致被混为一谈。

### 方法提取

- 方法节过于简略。
- 关键参数藏在补充材料里。
- 试剂型号、软件版本与随机种子缺失。
- 预处理描述不完整。
- 论文默认参数与仓库默认参数不一致。
- 方法引用另一篇方法，需要递归查找。
- following X 的表述掩盖了实际改动。
- 实验过程中的协议改动没有版本记录进入出版物。
- 排除条件散落各处。

### 实验记录

- 工作在台面发生，记录晚上补写。
- 失败实验最容易被漏记。
- 同一协议存在论文、Word 与 Notion 多份版本。
- 原始数据文件名无法反推实验。
- 样本编号与实验记录本编号脱节。
- 一张图无法追溯生成它的那次分析。
- 当时为什么这么做的理由没有留存。
- 负结果与放弃的尝试消失，日后被重新做一遍。
- 实验条件只存在于某位研究者的记忆里。

### 数据管理

- 原始、清洗与分析就绪三种状态混淆。
- 电子表格软件静默改变 CSV 列类型。
- 单位不统一。
- 缺失值混用 0、NA、空与 999。
- 列名随批次变化。
- 编码手册与数据集分离。
- 排除决策没有台账。
- 清洗过程不可逆。
- 复制粘贴中谱系丢失。
- 文件名累积：final.csv、final2.csv、really_final.csv。

### 定量分析

- 报告的 p 值与统计量对不上。
- 置信区间与点估计不一致。
- 百分比分母改动不写。
- N 在摘要、表格与流程图之间不一致。
- SD 与 SE 混用。
- 单尾双尾未说明。
- 多重检验校正不明。
- 变换尺度与原始尺度混用。
- 效应量定义不明。
- 仅有图表的数值需要数字化。
- 统计软件包的默认行为随版本变化。

### 系统综述

- 查询本身无法精确复现。
- 数据库导出格式互不兼容。
- 去重既误杀真实不同的论文，又漏掉版本重复。
- 标题与摘要筛选高度机械。
- 排除理由事后补填，台账不可靠。
- 全文缺失造成选择偏差。
- 同一研究的多份报告被计为多个研究。
- 同一队列的多篇论文被重复计入。
- 处理组、单位与时间点提取错误。
- 数据靠人工从图上读数。
- 效应方向被反转。
- 提取者之间的分歧难以追踪。
- 元分析的输入无法反推回论文原始表格。

### 定性研究

- 转写稿与音频时间戳失联。
- 访谈到开放编码到轴心编码到主题的谱系薄弱。
- 编码手册在分析期间持续变化。
- 合并编码后，旧片段为什么被重新归类无从追踪。
- 编码者间分歧没有结构化留存。
- 负面与证伪案例被主叙事淹没。
- 参与者属性与引语脱节。
- 匿名化之后分析语境丢失。

### 代码复现

- 仓库存在但没有精确提交号。
- 依赖未钉版本。
- CUDA、Python 与包版本矩阵脆弱。
- 数据集下载链接失效。
- 数据集版本不明。
- 检查点与论文不匹配。
- 预处理被隐藏。
- 随机种子未公开。
- 评估脚本与描述不一致。
- 数值行为依赖硬件。
- notebook 单元格不记录实际执行顺序。
- shell 命令只在作者机器上可用。
- 绝对路径硬编码。
- 外部 API 与数据库在发表后变更。
- 公开代码只有推理没有训练。

### 计算产物

- notebook 能跑一次，无法重跑。
- 手工改完 dataframe，代码不知情。
- 图不记录生成参数。
- 图经 Illustrator 二次编辑后与数据断链。
- 手稿表格手工复制，分析更新后表格过期。
- 报告数字来自旧模型版本。
- 舍入误差在多层复制中累积。

### 协作

- 最新版本在哪里无人知晓。
- 导师在 Word 批注，学生在 Overleaf 修改，两处分叉。
- Slack 与邮件里的关键决定不进项目记录。
- 离组学生的数据无人能找。
- 协作者改了一列数据不写原因。
- 权限设置让结果只有一个人能访问。
- 新人不知道哪些路线已经试过且失败。
- 交接只有文件，没有决策历史。

### 写作

- 论断先写，引文后找。
- 论文更新后，已加引文的论断不同步。
- 引言中几个相似论断来自重复文献。
- 方法与实际代码漂移。
- 结果与表格图数字漂移。
- 摘要数字不随正文修订更新。
- 局限性写得晚，遗漏已知的注意事项。
- 术语在不同章节不一致。
- 关键分析缺失直到手稿后期才发现。

### 投稿

- 各期刊格式要求不同。
- 转投就要重做引文、字数、章节与图。
- 报告规范选错。
- CONSORT、STROBE 与 PRISMA 条目拖到提交前才补。
- 作者贡献、利益冲突与数据可用性声明最后手填。
- 盲审稿残留作者身份。
- 补充材料命名与交叉引用出错。
- 图的分辨率、尺寸与字体不合目标格式。
- 引文元数据小错误批量积累。

### 同行评审与答复

- 评审意见与手稿修订没有一一对应关系。
- 多个评审提出同一个问题。
- 评审 A 与 B 的要求相互冲突。
- 修订后答复信的页码行号定位失效。
- 声称已修改，实际漏掉了同类文本的另外一处。
- 评审建议的引文本身可能不相关。
- 第二轮无法确认旧问题是否真正关闭。

### 审他人论文

- 核对引文是否真的支持论断速度很慢。
- 可疑表格数值需要手算。
- 与作者先前作品的重复难以批量核对。
- 数据与代码可用性链接要逐个点开。
- 方法缺项没有自动清单。
- 三百五十条参考文献中的自引模式靠肉眼检查。

### 基金申请

- 资助机会与机构指令会变。
- 模板版本过期。
- 页数、字体、页眉页脚与 URL 规则极其细碎。
- 简历与在研项目每次重复填写。
- 合作者使用过时的简历。
- 出版物要为每个申请书重选。
- 数据管理计划与实际研究工作流不一致。
- 同一机构数据复制到多个附件。
- 格式错误到提交门户才发现。
- 再投时无法把评审批评全量映射到修改后的申请书。

### 学位论文

- 学校模板与 Word、LaTeX 默认值冲突。
- 分节符与页码编号是纯粹的机械时间黑洞。
- 已发表章节与论文版本难以同步。
- 图表目录漏项。
- 格式检查规则高度地方化。

### 长期维护

- 发表后代码与数据停止维护。
- DOI 活着，外链死了。
- 依赖消失。
- 更正出来没人通知本地引用者。
- 系统综述两年后过期。
- 数据集新版本改变结论，旧分析不知情。

### 学习内容采集

- 讲义、笔记与卡片意味着同一内容录三遍。
- PDF、视频、讲义与习题各自孤立。
- 同一概念在不同材料里的讲法没有归并。
- 卡片脱离产生它的语境。
- 图像类知识制作遮挡卡片很慢。

### 学习状态

- 能识别被当作能回忆。
- 能识别被当作能生成与应用。
- 卡片成绩很好，真实问题不会做。
- 知道最终答案，不知道中间推理。
- 前置知识缺口不可见。
- 错题只记答案，不记错误机制。
- 易混概念被分开复习。
- 复习积压无限增长。
- 所有内容套用同一种间隔重复策略。

### 学习反馈

- 证明题卡住时不知道错在哪一步。
- 直接看解答产生学会的错觉。
- 完整答案破坏有益的挣扎过程。
- 没人判断证明是否严密。
- 同一错误反复出现，没有错误概念的身份。
- 缺少只给下一步的渐进式提示。

### 迁移

- 教材例题会做，变式不会。
- 卡片回忆不等于真实语言产出。
- 孤立事实的训练没有语境化提取。
- 没有从近迁移到远迁移的递进。
- 新问题该用哪个方法从未被训练。

### 元认知

- 学习者对会不会的判断很差。
- 简单重复带来的熟悉感冒充学会。
- 时间花在复习已经会的内容上。
- 失败的真实原因是知识缺口、提取失败还是策略选错，无从得知。

## 四、方法说明

清单继承第二节所记录的各来源核实状态。没有定量出处的条目，是对反复出现的社区报告所作的压缩表述；在因子分解矩阵中按假设处理，不按实测事实处理。下一步研究把每条映射到架构原语，度量哪些原语覆盖图集的最大份额。
