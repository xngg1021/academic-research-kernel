# Scholarly Terminology Guide (去黑话与多语言自然表达)

This repository provides software tools for researchers across the world. To ensure clarity and avoid confusing research users with software engineering house jargon, all user-facing documentation, skill frontmatter, and reporting outputs must use natural scholarly vocabulary.

## Banned User-Facing Jargon

The following literal machine-translations and house jargon are strictly prohibited in public-facing documentation and READMEs:
- `レジャー` (unnatural katakana transliteration of 'ledger' in Japanese)
- `영수증` (commercial payment receipt in Korean; use '근거 기록' / '검증 기록')
- `Beschneidungskausalität` (artificial German literal translation of prune causality)
- `causalité d’élagage` (artificial French literal translation)
- `causalidad de poda` (artificial Spanish literal translation)
- `台账内核` (unnatural Chinese accounting term used for research provenance)
- `Truth Authority` (unnecessary conceptual baggage)
